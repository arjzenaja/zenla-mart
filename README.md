**Zenla Mart Mobile** membawa pengalaman belanja Zenla Mart langsung ke genggaman Anda. Dibangun dengan Expo dan React Native untuk performa lintas platform yang optimal.

## ✨ Fitur Utama
- 📱 **Mobile UI Modern**: Antarmuka pengguna yang bersih dan intuitif khusus untuk perangkat mobile.
- 🧭 **Navigasi Cepat**: Menggunakan Drawer dan Tab navigation untuk akses fitur yang mudah.
- 📸 **Profil & Alamat**: Kelola akun dan lokasi pengiriman dengan integrasi kamera (Expo Image Picker).
- 🧾 **Laporan Pesanan**: Lihat riwayat belanja dan generate invoice PDF langsung dari ponsel.
- ⚡ **Performa Tinggi**: Animasi halus menggunakan React Native Reanimated.

## 🛠️ Tech Stack
- **Framework**: Expo 54 (SDK 54)
- **Core**: React Native 0.81
- **Navigation**: React Navigation (Stack, Drawer, Bottom Tabs)
- **Icons**: Lucide React Native
- **Storage**: Async Storage
- **Utilities**: Axios, Expo Print, Expo Sharing, Reanimated

## 🚀 Memulai (Local Setup)

1.  **Instalasi Dependensi**:
    ```bash
    npm install
    ```

2.  **Jalankan di Development Mode**:
    ```bash
    npx expo start
    ```
    Gunakan aplikasi **Expo Go** di Android/iOS untuk men-scan QR code yang muncul.

3.  **Jalankan di Simulator/Emulator**:
    - Tekan `a` untuk Android Emulator.
    - Tekan `i` untuk iOS Simulator.
